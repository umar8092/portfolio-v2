# Muhammad Umar, portfolio (v2 design)

A redesigned version of https://umar8092.github.io: the same projects, experience and apps list, with a project viewer, a searchable apps card and a day/night toggle.

Plain HTML, CSS and JavaScript. Open `index.html` or serve the folder with `python3 -m http.server`.

Brand logos belong to their respective owners and are shown only to indicate which apps have been integrated.
